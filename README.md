## 📚 Projek Kuliah — Data Science

Repository ini berisi kumpulan project, praktikum, dan tugas perkuliahan selama menempuh pendidikan di bidang Data Science. Berbagai project di dalam repository ini mencakup machine learning, deep learning, big data, data engineering, statistika, visualisasi data, dan pengembangan aplikasi.

Repository ini dibuat sebagai dokumentasi pembelajaran, implementasi konsep, serta portofolio pengembangan keterampilan teknis.

## 🛠️ Teknologi dan Topik

Project dalam repository ini mencakup beberapa bidang berikut:

- Machine Learning: Random Forest, K-Nearest Neighbors (KNN), dan klasifikasi.
- Deep Learning: Residual Network (ResNet) dan Convolutional Block Attention Module (CBAM).
- Big Data & Data Engineering: Apache Spark dan Medallion Architecture.
- Data Warehouse: Perancangan warehouse untuk analisis preferensi konsumen.
- Optimization Algorithms: Bat Algorithm dan Swarm Intelligence.
- Statistics & Data Analysis: Regresi linear dan analisis data.
- Data Visualization: Analisis pergerakan pengunjung dan hubungan antar lokasi.
- Programming & Application Development: Struktur data dan pengembangan aplikasi web.
- MLOps: Dokumentasi modul praktikum dan pengelolaan project machine learning.
- Teknologi yang digunakan pada setiap project dapat berbeda sesuai dengan kebutuhan dan implementasinya.

## 🎯 Tujuan Repository

- Mendokumentasikan project dan praktikum perkuliahan.
- Menerapkan konsep Data Science melalui project nyata.
- Mengembangkan keterampilan pemrograman, analisis data, dan machine learning.
- Menyimpan hasil pembelajaran dalam repository yang terstruktur.
- Menjadi portofolio akademik untuk menunjukkan pengalaman dan kompetensi teknis.
